# 인터넷 비교견적 검수표

## 요청 범위

- [ ] 요청된 전체 품목을 빠짐없이 포함한다.
- [ ] 사용자가 지정한 현재 파일과 문서 묶음을 유지했다. 한 파일 수정 요청을 별도 본견적서·비교견적서 작성으로 대신하지 않았다.
- [ ] 모든 품목에 요구된 수의 비교견적이 있다.
- [ ] `--expected-main`과 `--comparisons-per-main`이 실제 요청 범위와 같다.
- [ ] 본견적을 비교견적 수에 포함하거나 붙임 부수로 비교 판매처 수를 줄이지 않는다.
- [ ] 품목별 비교견적 번호가 1부터 연속되고 판매처가 중복되지 않는다. 모든 HWPX 본문 구역을 검사한다.
- [ ] 다른 제품 비교가 명시적으로 허용된 경우 실제 제품 차이를 표시하고, 동일 제품 검증의 성공으로 대신하지 않는다.

## 지정 판매처·호환 경로 확인 및 본견적 재산정

- [ ] 사용자가 지목한 판매처·허용한 호환 경로를 실제로 확인했고, 한 판매처의 품절만으로 시장 구매 불가나 남은 구매 의존사항을 단정하지 않았다. 해당 지시가 없으면 비적용으로 기록한다.
- [ ] 적용 품목마다 실제 출처·확인 시점과 호환 근거, 선택 옵션, 묶음·쌍당 구성 수, 승인 주문수량·실제 총수량, 선택 조건의 현재 재고 및 배송·할인 반영 총액을 작업 기록에서 대조했다. 미확인 조건을 완료로 처리하지 않았다.
- [ ] 금액 문서 작성·수정 전에 영향받는 본견적 전체 품목을 최신 실제 출처 가격으로 재산정하고, 함께 구매하는 품목·주문 묶음·배송·할인을 포함한 전체 합계와 문서 금액을 대조했다. 오래된 추정가·임의 증액·미승인 수량 증가·화면 변조로 예산을 맞추지 않았다.
- [ ] 최저가를 일률적으로 강제하지 않되 선택한 출처의 실제 가격과 선택 근거를 확인했다. 호환품 구매 허용을 유사제품 비교 허용으로 확대하지 않았고, 갱신된 본견적에 대해 동일제품 원칙·명시적 예외와 엄격히 높은 실제 비교 총액을 다시 확인했다.

## 견적 일치

- [ ] 동일제품 항목의 제조사·모델·규격·구성·옵션·주문수량과 단위가 같다.
- [ ] 허용된 유사제품은 실제 브랜드·모델·포장·주문수량과 동등한 총수량 또는 총중량 및 확인된 차이를 표시한다. 미확인 조건은 문서 밖 검수 기록과 사용자 보고에 남긴다.
- [ ] 비교품 상호 동일성 예외는 미확인 보고 후 해당 품목을 각각 유사품으로 채우라는 별도 명시 지시를 대조한 경우에만 적용했다. 각 견적에 확인된 실제 차이를 표시하고, 동일성 미확인은 문서 밖에 기록·보고했다. 실제 수량·화면·배송 및 할인 반영 총액을 각각 확인했다. 예외를 동일성이나 기관 승인 확인으로 보고하지 않았다.
- [ ] 비교견적의 판매처가 본견적 판매처와 다르다.
- [ ] 동일제품과 허용된 유사제품 모두 배송비·실제 적용 할인 반영 비교 총액이 본견적보다 높다. 낮거나 같은 견적은 다른 판매처 견적으로 교체한다.

## 캡처 증빙

- [ ] 저장된 각 원본과 정확한 최종 문서의 각 삽입 그림·쪽 렌더링을 직접 확인하여 포인터·클릭 후광·툴팁·호버 강조가 없음을 확인했다. 오염된 증빙은 원본을 재촬영했으며 픽셀을 덧칠하거나 지우지 않았다.

- [ ] 검색·추천·미니샵 목록을 상세 견적 증빙으로 통과시키지 않았다. 판매처가 그림 위의 편집 가능한 큰 글자로 구분되며, 불필요한 URL을 추가하지 않았다.
- [ ] 품목마다 실제 상품 또는 포장 사진이 보인다. 가독성 개선이나 포인터 회피를 위한 자르기로 사진을 제거하지 않았다.
- [ ] 판매처와 해당 상품의 실제 최종 금액이 같은 원본 사진 안에서 함께 읽힌다. 편집 가능한 제목이나 별도 화면 조각으로 업체명 누락을 대신하지 않는다.
- [ ] 다른 상품·추천 상품이 캡처에 섞이지 않고, 표시 합계가 해당 견적 상품에만 대응한다.
- [ ] 판매처, 상품명·모델명, 선택 옵션이 보인다.
- [ ] 선택 수량과 해당 수량의 최종 총액이 함께 보인다.
- [ ] 배송비가 총액에 영향을 주면 배송비 조건이 보인다.
- [ ] 쿠폰 또는 회원 할인가를 사용하면 적용 여부가 화면에서 확인된다.
- [ ] 입력 수량과 갱신된 상품 합계가 일치한다. 배송비·할인 반영 결제금액을 설명문과 대조한다.
- [ ] 포인터·클릭 표시·호버 설명·선택 강조가 없다. 오염된 화면은 재촬영하며 AI 지우기·픽셀 덧칠을 하지 않는다.
- [ ] 캡처가 흐리거나 잘리지 않았으며 가격과 수량을 인쇄물에서도 읽을 수 있다.

## 문서 편집성과 배열

- [ ] 품목별로 본견적 다음에 해당 품목의 비교견적이 이어진다.
- [ ] 사용자 수정본의 간결한 배치를 기준으로 불필요한 쪽 나눔과 여백을 줄였다. 같은 품목의 견적을 함께 배치할 수 있는데도 각각 한 쪽을 강제하지 않았다.
- [ ] 장수 감축 뒤에도 요구된 견적 수와 실제 사진·옵션·수량·가격이 모두 남고 인쇄 가독성이 유지된다.
- [ ] 제목·파일명·소제목의 각 문구에 양식, 사용자 지시 또는 문서 역할 근거가 있다. 온라인·인터넷 등 덧붙인 수식어와 같은 사실을 반복하는 설명을 제거했다.
- [ ] 편집 가능한 설명문에는 확인된 품목·규격·수량·금액·출처와 필요한 구매 조건만 적었다. 검증 상태나 작성 경위는 문서 밖에 두고 미확인 필수 조건은 미완료로 남겼다.
- [ ] 모든 설명문이 캡처와 분리된 편집 가능한 HWPX 텍스트다.
- [ ] 모든 설명문에 공식몰·네이버쇼핑·11번가 등 판매 경로를 식별할 수 있는 `출처`가 글자로 적혀 있다.
- [ ] 모든 캡처 그림에 `글자처럼 취급`이 적용되어 있다.
- [ ] 설명문과 해당 캡처가 같은 쪽에 있다.
- [ ] 빈 쪽, 겹침, 잘림 또는 품목 순서 뒤바뀜이 없다.

## 최종 검증

- [ ] 견적 증빙 완료를 선언하는 경우 정확한 최종 HWPX·원본·쪽 이미지의 해시와 그림별 실제 시각 검수가 연결된 `verify_quote_capture_review.py` 검사를 통과했다. 미확보 증빙은 가독성 수정 완료와 구분하여 보고했다.
- [ ] 검증 스크립트가 성공했다.
- [ ] 두 개 이상의 독립 HWPX 검사기가 성공했다.
- [ ] 설치된 한글에서 정확한 최종 파일을 열었다.
- [ ] 현재 쪽 렌더링으로 전 쪽을 확인했다. PDF가 필요한 검증이면 최소 임시 파일만 사용했다.
- [ ] 요청 또는 확인된 제출·인쇄 요건 없이 견적 PDF·검토용 모음·준비현황 PDF를 추가로 만들지 않았다.
- [ ] 정확한 최종 출력에서 모든 본견적·비교견적의 상품 사진과 결제정보를 함께 확인했다. 그림 개수나 원본 캡처의 사진 존재만으로 통과시키지 않는다.
- [ ] 추가·제외·수량 변경이 공문·계획서·구매내역·견적·검토용 모음의 모든 관련 내용과 합계에 반영됐다.
- [ ] 종류 수·포장 수·실제 총수량을 기준 목록과 대조했고, 추가 품목의 필요성·활용 내용 및 제외 품목의 링크·캡처도 확인했다.
- [ ] 사용자 수정본과 이전 작성본의 차이를 확인하고, 요청하지 않은 문구·단위·배치·결재 정보가 되돌아가지 않았다.
- [ ] 최종 대상 경로의 SHA-256이 검증한 파일과 같다.
