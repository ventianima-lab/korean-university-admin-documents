# 인터넷 비교견적 검수표

## 요청 범위

- [ ] 요청된 전체 품목을 빠짐없이 포함한다.
- [ ] 모든 품목에 요구된 수의 비교견적이 있다.
- [ ] `--expected-main`과 `--comparisons-per-main`이 실제 요청 범위와 같다.
- [ ] 본견적을 비교견적 수에 포함하거나 붙임 부수로 비교 판매처 수를 줄이지 않는다.
- [ ] 품목별 비교견적 번호가 1부터 연속되고 판매처가 중복되지 않는다. 모든 HWPX 본문 구역을 검사한다.
- [ ] 다른 제품 비교가 명시적으로 허용된 경우 실제 제품 차이를 표시하고, 동일 제품 검증의 성공으로 대신하지 않는다.

## 견적 일치

- [ ] 동일제품 항목의 제조사·모델·규격·구성·옵션·주문수량과 단위가 같다.
- [ ] 허용된 유사제품은 실제 브랜드·모델·포장·주문수량과 동등한 총수량 또는 총중량, 차이·미확인 조건을 표시한다.
- [ ] 비교견적의 판매처가 본견적 판매처와 다르다.
- [ ] 동일제품과 허용된 유사제품 모두 배송비·실제 적용 할인 반영 비교 총액이 본견적보다 높다. 낮거나 같은 견적은 다른 판매처 견적으로 교체한다.

## 캡처 증빙

- [ ] 품목마다 실제 상품 또는 포장 사진이 보인다. 가독성 개선이나 포인터 회피를 위한 자르기로 사진을 제거하지 않았다.
- [ ] 판매처, 상품명·모델명, 선택 옵션이 보인다.
- [ ] 선택 수량과 해당 수량의 최종 총액이 함께 보인다.
- [ ] 배송비가 총액에 영향을 주면 배송비 조건이 보인다.
- [ ] 쿠폰 또는 회원 할인가를 사용하면 적용 여부가 화면에서 확인된다.
- [ ] 입력 수량과 갱신된 상품 합계가 일치한다. 배송비·할인 반영 결제금액을 설명문과 대조한다.
- [ ] 포인터·클릭 표시·호버 설명·선택 강조가 없다. 오염된 화면은 재촬영하며 AI 지우기·픽셀 덧칠을 하지 않는다.
- [ ] 캡처가 흐리거나 잘리지 않았으며 가격과 수량을 인쇄물에서도 읽을 수 있다.

## 문서 편집성과 배열

- [ ] 품목별로 본견적 다음에 해당 품목의 비교견적이 이어진다.
- [ ] 모든 설명문이 캡처와 분리된 편집 가능한 HWPX 텍스트다.
- [ ] 모든 설명문에 공식몰·네이버쇼핑·11번가 등 판매 경로를 식별할 수 있는 `출처`가 글자로 적혀 있다.
- [ ] 모든 캡처 그림에 `글자처럼 취급`이 적용되어 있다.
- [ ] 설명문과 해당 캡처가 같은 쪽에 있다.
- [ ] 빈 쪽, 겹침, 잘림 또는 품목 순서 뒤바뀜이 없다.

## 최종 검증

- [ ] 검증 스크립트가 성공했다.
- [ ] 두 개 이상의 독립 HWPX 검사기가 성공했다.
- [ ] 설치된 한글에서 정확한 최종 파일을 열었다.
- [ ] 최신 PDF 또는 쪽별 이미지로 전 쪽을 확인했다.
- [ ] 정확한 최종 출력에서 모든 본견적·비교견적의 상품 사진과 결제정보를 함께 확인했다. 그림 개수나 원본 캡처의 사진 존재만으로 통과시키지 않는다.
- [ ] 추가·제외·수량 변경이 공문·계획서·구매내역·견적·검토용 모음의 모든 관련 내용과 합계에 반영됐다.
- [ ] 종류 수·포장 수·실제 총수량을 기준 목록과 대조했고, 추가 품목의 필요성·활용 내용 및 제외 품목의 링크·캡처도 확인했다.
- [ ] 사용자 수정본과 이전 작성본의 차이를 확인하고, 요청하지 않은 문구·단위·배치·결재 정보가 되돌아가지 않았다.
- [ ] 최종 대상 경로의 SHA-256이 검증한 파일과 같다.
