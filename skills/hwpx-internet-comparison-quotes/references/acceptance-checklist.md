# 인터넷 비교견적 검수표

## 견적 일치

- [ ] 본견적과 비교견적의 제조사와 모델명이 같다.
- [ ] 규격, 구성품과 선택 옵션이 같다.
- [ ] 수량과 수량 단위가 같다.
- [ ] 비교견적의 판매처가 본견적 판매처와 다르다.
- [ ] 각 비교견적의 최종 총액이 본견적 총액보다 높다.

## 캡처 증빙

- [ ] 판매처, 상품명·모델명, 선택 옵션이 보인다.
- [ ] 선택 수량과 해당 수량의 최종 총액이 함께 보인다.
- [ ] 배송비가 총액에 영향을 주면 배송비 조건이 보인다.
- [ ] 쿠폰 또는 회원 할인가를 사용하면 적용 여부가 화면에서 확인된다.
- [ ] 캡처가 흐리거나 잘리지 않았으며 가격과 수량을 인쇄물에서도 읽을 수 있다.

## 문서 편집성과 배열

- [ ] 품목별로 본견적 다음에 해당 품목의 비교견적이 이어진다.
- [ ] 모든 설명문이 캡처와 분리된 편집 가능한 HWPX 텍스트다.
- [ ] 모든 설명문에 공식몰·네이버쇼핑·11번가 등 판매 경로를 식별할 수 있는 `출처`가 글자로 적혀 있다.
- [ ] 모든 캡처 그림에 `글자처럼 취급`이 적용되어 있다.
- [ ] 설명문과 해당 캡처가 같은 쪽에 있다.
- [ ] 빈 쪽, 겹침, 잘림 또는 품목 순서 뒤바뀜이 없다.

## 최종 검증

- [ ] 검증 스크립트가 성공했다.
- [ ] 두 개 이상의 독립 HWPX 검사기가 성공했다.
- [ ] 설치된 한글에서 정확한 최종 파일을 열었다.
- [ ] 최신 PDF 또는 쪽별 이미지로 전 쪽을 확인했다.
- [ ] 최종 대상 경로의 SHA-256이 검증한 파일과 같다.
