# 구매 서류 변경 대조

문서별 수정이 서로 달라지거나 추가 품목이 활용계획에서 빠졌을 때 적용한다. 현재 요청의 기준 목록과 파일별 대조 결과는 작업 기록에 보존한다. 실제 구매 기록을 이 스킬에 복사하지 않는다.

## 편집 전 기준

- 사용자 수정본과 이전 작성본을 비교하여 유지할 문구·문단·표 정렬·단위·붙임·결재 정보와 새로 바꿀 사실을 구분한다. 파일명이나 수정 시각만으로 작성본을 고르지 않는다.
- 기준 목록에는 개별 구매 품목, 공문용 대표 품목군과 종류 수, 규격, 포장 구성, 주문 단위와 수량, 물리적 총수량, 단가·실제 할인·배송비·결제금액, 지급수단을 적는다. 품목군 종류 수는 상세 품목을 중복 없이 세어 산출한다.
- `추가 N개`는 기존 수량에 더한 최종 총수량으로 확정한다. `전체 제외`는 수량을 0으로 확정하고 본문·표·견적에서 제거한다. 과거 수량을 현재 기준으로 재사용하지 않는다.
- 비교견적 수는 사용자 지시나 적용 가능한 기관 기준에서 가져온다. `비교견적 2부`는 본견적 1건과 비교견적 2건이며, 붙임 문서의 `각 1부`나 현재 확보 건수는 이 기준을 낮추는 근거가 아니다. 근거가 서로 충돌하면 그 쟁점만 확인하고 나머지 작업을 진행한다.

## 위치별 대조

| 수정 대상 | 기준 목록과 대조할 위치 |
| --- | --- |
| 사전품의 공문 | 대표 품목군·종류 수, 규격·실제 수량, 금액 및 예산집행 계획 |
| 세부 운영계획 | 구매 목적·구매 내용·활용 방법, 각 산출근거와 지급수단 |
| 물품 활용계획 | 물품명·구입 필요성·활용 내용·기대 효과에 추가·제외 품목 반영 |
| 구매내역 | 개별 품목·규격·주문수량, 할인·배송비·합계·잔액, 유효한 상품 링크 |
| 본견적·비교견적 | 실제 옵션·수량과 갱신된 합계, 배송비·할인, 편집 가능한 설명문, 요구된 건수와 서로 다른 판매처 |
| 검토용 모음 | 최신 구성요소와 같은 내용·쪽 순서·쪽 수, 오래된 표지·합계·캡처 잔존 여부 |

종류 수·포장 수·주문수량·물리적 총수량을 같은 값으로 맞추지 않는다. `대표 품목 등 차류 N종`은 품목군 이름이며, 규격·수량란에는 실제 포장과 수량을 적는다. 판매 경로나 업체명은 출처·구입처란에 둔다. 본견적과 유사제품의 포장이 다르면 실제 주문 단위를 보존하고 동등한 총중량·총수량을 별도로 확인한다.

## 완료 판단

- 최신 원본과 대조한 변경 목록으로 누락 및 요청하지 않은 원복을 확인한다. 이전 실행 스크립트나 백업을 쓸 때도 현재 원본·기준 목록과 다시 대조한다.
- 제외된 모델명·품목명·옛 수량·옛 금액을 편집 가능한 본문·표·활성 링크에서 찾고 캡처와 최종 PDF도 직접 확인한다. 공통 단어를 무조건 삭제하지 않으며 별도 범위에서 유지하도록 한 품목은 보존한다.
- 숫자가 맞아도 필요성·활용 방법에 새 품목이 빠져 있으면 미완료다. 전체 품목·요구된 비교견적 수에 대한 검사에서 통과해야 완료로 보고한다.
- 캡처 검사와 최신 PDF 시각 검수는 별개다. 포인터·클릭 표시를 없애고 재촬영한 원본으로 교체하며, 자동 검사가 화면 진위나 커서 부재까지 확인했다고 주장하지 않는다.
