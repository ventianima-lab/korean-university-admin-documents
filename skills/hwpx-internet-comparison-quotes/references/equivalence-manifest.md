# 명시적으로 허용된 유사제품 비교

동일 제품 비교가 기본이다. 사용자가 유사제품을 허용한 품목만 예외로 처리하며, 본견적의 구매 제품을 바꾸지 않는다. 차류는 종류·수확 조건·총중량을, 실습용품은 용도·필수 규격·총수량을 실제 근거로 대조한다. 브랜드·모델·포장·등급·산지의 차이 또는 미확인 조건을 숨기지 않는다. 포장 수가 다르면 실제 주문 단위와 동등한 총중량·총수량을 각각 적는다.

`--equivalence-manifest`의 JSON 형식은 다음과 같다. 숫자는 예시이며 기관 기준으로 일반화하지 않는다.

```json
{
  "authorization": "The user explicitly allowed a similar product when the same model was unavailable.",
  "items": [
    {
      "item": "실습용품",
      "main": {"product": "브랜드A 모델A", "quantity": "2개", "total": 24000, "source": "판매처A", "seller_identity": "사업자A"},
      "comparisons": [
        {
          "product": "브랜드B 모델B",
          "quantity": "2개",
          "total": 30000,
          "source": "판매처B",
          "seller_identity": "사업자B",
          "kind": "similar",
          "basis": "같은 용도와 필수 규격, 총 2개",
          "differences": "브랜드와 모델이 다름."
        }
      ]
    }
  ]
}
```

- `items`는 문서의 전체 본견적 수와 순서가 같아야 한다. `product`, `quantity`, `total`, `source`는 설명문의 실제 값과 일치해야 한다.
- `seller_identity`는 실제 거래업체의 확인된 상호를 적는다. 같은 업체가 여러 쇼핑몰 이름으로 나타나면 같은 식별값을 사용하고 중복으로 실패시킨다. 단순 표기 일치 검사는 실제 사업자의 동일성을 증명하지 않으므로 별도로 사업자정보를 확인한다.
- 동일제품 항목은 `kind: "identical"`로 적는다. 본견적과 제품·수량이 같아야 한다. 유사제품은 `kind: "similar"`, 비교 기준 `basis`, 문서에 그대로 표시할 차이 `differences`가 필요하다.
- 유사제품을 포함한 품목의 비교견적이 여러 건이면 원칙적으로 서로 같은 제품·구성·옵션·수량이어야 한다. 같은 상품을 여러 판매처에서 확보하지 못했거나 상호 동일성을 확인하지 못했다고 알린 뒤에도 사용자가 해당 품목을 각각 유사품으로 채우라고 별도 명시한 경우에만 예외로 한다. 일반적인 유사품 허용만으로 예외를 적용하지 않는다. 해당 품목 객체에 `comparison_identity_exception`을 `{ "unverified_identity_report": "미확인 사실을 알린 근거", "explicit_instruction": "각 유사품으로 채우라는 사용자 원문", "reference": "대화 위치" }`로 기록한다. 세 항목은 모두 공백이 아닌 문자열이어야 하며, 작성자가 실제 보고와 지시의 의미·범위를 직접 확인한다. 도우미는 입력된 문장의 진위나 의미를 판정하지 않는다.
- 예외가 적용되면 각 비교품의 실제 상품·구성·수량과 확인된 차이 또는 상호 동일성 미확인을 해당 견적의 `differences`와 문서에 짧게 표시한다. 각 비교품의 용도와 비교 기준, 실제 수량·금액·판매처 및 원본 캡처를 따로 확인하고, 동일 제품으로 입증되었다고 표현하지 않는다. 도우미는 비교품 간 제품·수량 일치만 면제하며 각 명세와 문서 값, 각 차이 표시, 판매처 독립성 및 엄격한 고가 조건은 계속 검사한다. 화면의 신뢰성 및 수량의 비교 적정성은 직접 확인한다.
- 유사제품 대체 허용은 가격 조건의 면제가 아니다. 비교 총액이 본견적보다 낮거나 같으면 다른 판매처를 확보한다. `allow_lower_price` 같은 명세의 임의 표시로 가격 검사를 면제하지 않으며 실제 가격을 부풀리지 않는다.
- 문서에는 해당 품목의 `유사제품` 표시와 `differences` 문구를 편집 가능한 글자로 넣는다. 명세만 작성하고 실제 문서의 구분을 생략하면 안 된다.
- 비교견적이 여러 건이면 각 설명문 뒤에 그 비교 제품의 차이를 적는다. 다른 비교견적의 문구만 있는 경우에는 해당 견적의 차이를 표시한 것으로 인정하지 않는다.
- 명세는 실제 설명문의 일치·누락을 검사하는 장치다. 스크린샷의 진위, 수량 선택 상태, 비교 규격의 적절성과 기관의 승인 여부를 대신 증명하지 않는다. 원본 화면과 최종 PDF를 직접 확인한다.
