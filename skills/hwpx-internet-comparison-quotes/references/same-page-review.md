# 같은 쪽 검수 기록

이 절차는 사용자가 품목별 비교견적 1·2를 같은 쪽에 명시한 경우의 추가 관문이다. 미리 정한 전체 품목 수와 캡처 수를 사용한다. 8품목이면 8쌍과 16개 그림이다. 작업 전 현재 파일을 읽기 전용 스냅샷으로 보존하고 임시 PDF를 정확한 최종 HWPX에서 출력한다. PDF는 인쇄 기준과 동일한 크기로 전 페이지를 직접 확인한다. 비교견적 1·2 각각의 판매처와 상품·옵션·수량·가격·배송 등 필수 내용, 이미지와 제목의 대응, 잘림·겹침을 확인한다. 확인 전 값은 true로 쓰지 않는다.

비공개 JSON 예시 (경로는 명령 인수로 전달):

```json
{
  "document_sha256": "<최종 HWPX SHA-256>",
  "baseline_sha256": "<작업 전 HWPX SHA-256>",
  "pdf_sha256": "<최종 출력 PDF SHA-256>",
  "pdf_export_from_document_sha256": "<최종 HWPX SHA-256>",
  "pdf_export_verified": true,
  "pairs": [{
    "picture_ids": ["101", "102"],
    "page": 1,
    "markers": ["해당 견적 1에만 나타나는 판매처 등 표식", "해당 견적 2에만 나타나는 판매처 등 표식"],
    "both_pictures_on_page": true,
    "labels_match_pictures": true,
    "all_details_readable": true,
    "no_clipping_or_overlap": true,
    "same_item_quotes_1_and_2": true
  }]
}
```

`pairs`는 모든 요청 품목을 저장된 그림 순서대로 포함한다. 각 표식은 HWPX와 PDF 텍스트에서 읽히고 전체 출력 중 해당 쪽에만 나타나야 한다. 텍스트 추출이 불가능하거나 표식이 중복되면 통과하지 않는다. `pdftotext`가 필요하며 경로가 PATH에 없으면 `--pdftotext`로 지정한다. 검사는 그림 ID와 개수·순서, 원본 대비 BinData 해시 다중집합과 텍스트와 순서, 출력 PDF 내 표식의 실제 쪽, 문서·PDF 해시를 확인한다. 작업이 레이아웃만 바꾸는 범위라면 문구나 캡처가 바뀌는 것은 실패다. 별도 허용된 내용 수정은 수동으로 근거와 차이를 대조한 후 수정된 기준 스냅샷을 별도로 확정한다.

이 검사는 PDF가 HWPX에서 실제로 출력됐는지, 표식과 그림의 실제 대응, 캡처의 인쇄 가독성이나 증빙 진위를 자동으로 입증하지 않는다. 해당 값은 정확한 파일을 열어 사람이 직접 확인한 증언이다. PDF의 출력 경로·인쇄 설정 및 검토 범위를 비공개 기록으로 남긴다. 장바구니 출처·진위와 금액 비교 등의 기존 검증은 별도로 수행한다. 서로 다른 쪽이라면 문구만 옮기거나 값을 조작해 검사를 통과시키지 않는다.

## 승인된 표 밖 표시 변경

실제 사용자의 지시로 중복 품목 제목을 삭제하거나 판매처 앞에 `비교견적 1 | ` 또는 `비교견적 2 | `만 추가한 경우에만, 비공개 JSON에 `authorized_text_edits` 배열을 추가한다. 각 항목은 작업 전 파일의 공백 아닌 `hp:t` 순서 기준 0부터의 `baseline_index`, 정확한 `before`, 정확한 `after`(삭제는 빈 문자열), `kind`(`remove_duplicate_title` 또는 `prefix_quote_number`), `independently_reviewed: true`, 실제 지시를 식별하는 `instruction_reference`가 필요하다. 각 전후 문자열과 대상이 사용자의 지시와 일치하는지 독립 확인하고 기록한다. 동일 텍스트라도 인덱스가 다른 위치는 별도 승인해야 한다.

표 안 텍스트는 예외 대상이 아니다. 표의 모든 셀 텍스트와 순서, 각 그림 ID·바이너리 바이트·순서가 기준과 다르면 실패한다. 다른 종류의 수정은 이 예외로 허용하지 않는다. 예외를 적용한 전후 텍스트 전체가 일치해야 하며, 단지 검사를 통과시키기 위해 기준 파일을 교체하지 않는다.
