# HWPX 인터넷 비교견적

인터넷 비교견적 문서를 만들 때는 `hancom-hwpx-documents`의 보존·검증 절차를 함께 적용한다. 후속 편집을 시작할 때마다 작업 폴더를 다시 확인하고, 현재 최종본이 있으면 그 파일을 내용·시각 기준으로 삼아 작업 전 사본을 보존한다. 더 최신인 최종본이 있는데도 이전 구성요소, 중간본, 백업본, 검증본 또는 과거 실행 산출물에서 문서를 다시 만들지 않는다. 최종본을 교체하기 전에는 기존 최종본의 해시와 페이지 수, 이미 반영된 견적·수량·금액·사진을 후보와 대조하고, 새 요청과 무관한 기존 내용이 하나라도 빠지면 덮어쓰지 않는다.

## 비교견적 성립 조건

- 본견적과 비교견적은 제조사, 모델명, 규격, 구성품, 선택 옵션과 수량이 같아야 한다.
- 비교견적은 본견적과 다른 판매처에서 확보한다.
- 비교견적 화면의 최종 총액은 본견적의 최종 총액보다 높아야 한다.
- 판매처만 다르고 제품 조건이 완전히 같은 견적을 사용한다. 다른 제품, 유사 모델, 다른 구성 또는 다른 수량으로 대체하지 않는다.
- 조건을 충족하는 화면을 찾지 못하면 다른 제품으로 채우지 말고 `비교견적 확보 실패`로 보고한다.

## 캡처 기준

각 캡처에는 다음 정보가 한 화면에서 확인되어야 한다.

- 판매처 또는 쇼핑몰 식별 정보
- 정확한 상품명과 모델명
- 선택한 규격·구성·옵션
- 본견적과 같은 선택 수량
- 해당 수량의 최종 총액
- 배송비가 총액에 영향을 주면 배송비 또는 무료 배송 표시

단가만 보이거나 수량 선택 전 화면, 장바구니 합계가 가려진 화면, 쿠폰 적용 여부가 불분명한 화면은 완료 증빙으로 사용하지 않는다. 사용자가 캡처를 제공했으면 새로 검색하기 전에 제공된 화면부터 검사한다.

## HWPX 작성 규칙

1. 품목별로 `본견적 → 비교견적 1 → 비교견적 2` 순서를 유지한다. 사용자가 요구한 비교견적 수가 다르면 그 수를 따른다.
   - 한 문서에 품목이 여러 개면 한 본견적 쪽에 합치지 말고, 첫 품목의 본견적과 비교견적을 끝낸 뒤 다음 품목의 본견적과 비교견적을 배치한다.
2. 각 그림 바로 위에 다음 형식의 편집 가능한 한글 문단을 둔다.
   - 본견적: `품목 | 제조사 모델명·구성 | 수량 N개 | 총액 N원 | 출처 쇼핑몰명`
   - 비교견적: `비교견적 1 | 품목 | 제조사 모델명·구성 | 수량 N개 | 총액 N원 | 출처 쇼핑몰명`
   - `출처`에는 `제조사 공식몰`, `네이버쇼핑`, `11번가`, `쿠팡`, `GS SHOP`처럼 문서만 보고도 판매 경로를 구분할 수 있는 명칭을 쓴다. 오픈마켓 안에서 판매자 구분이 필요하면 `11번가(판매자명)`처럼 병기한다.
3. 설명문을 캡처 이미지에 합성하거나 이미지로 만들지 않는다. HWPX 본문에서 선택·수정할 수 있는 실제 텍스트여야 한다.
4. 캡처 이미지는 비율을 유지하여 축소하고 `글자처럼 취급`을 켠다. HWPX XML에서는 해당 `hp:pic`의 `hp:pos`에 `treatAsChar="1"`, `flowWithText="1"`이 있어야 한다.
5. 가격, 수량, 상품명 또는 판매처가 잘리지 않도록 한다. 증빙 내용이 흐려질 정도로 축소하지 않는다.
6. 한 쪽에 비교견적 두 건을 넣어도 되지만, 두 설명문과 두 캡처가 모두 읽힐 때만 허용한다. 그렇지 않으면 쪽을 나눈다.
7. 기존 양식의 여백, 글꼴, 문단 간격과 품목 순서를 유지한다. 빈 쪽이나 캡처와 설명문이 분리된 쪽을 남기지 않는다.
8. 한컴 변환 또는 PDF 출력에서 캡처의 투명 영역이나 검은 픽셀이 페이지 배경으로 번지는 현상을 막기 위해, 삽입용 사본은 흰 배경의 RGB 이미지로 평탄화한다. 원본 캡처는 별도로 보존한다.
9. 사용자가 `세로`를 지정하면 A4 세로 방향을 문서 속성에 명시하고, 설치된 한글에서 변환한 최종 PDF의 모든 쪽이 세로인지 직접 확인한다.

## 완료 검증

완료 전에 [검수표](references/acceptance-checklist.md)를 적용한다. 이어서 다음 명령으로 편집 가능한 설명문, 순서, 수량, 총액 비교와 `글자처럼 취급` 속성을 검사한다.

```powershell
python scripts/verify_quote_hwpx.py "<최종.hwpx>" --expected-main <본견적수> --comparisons-per-main <품목당비교견적수>
```

스크립트 검사를 통과한 뒤 Kordoc, `python-hwpx`, `pyhwpxlib`, 설치된 한글 열기와 PDF 렌더링으로 정확한 최종 파일을 확인한다. 실제 화면에서 모든 캡처의 수량·총액·동일 제품 여부와 가독성을 직접 검사한다. 하나라도 확인되지 않으면 완료로 보고하지 않는다.
