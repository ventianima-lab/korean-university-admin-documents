# 학생 단톡방 공지

공지 작성에는 [공통 작성 정책](../submission-ready-authoring/SKILL.md)의 입력 완결성과 사용자 지정 색상 범위를 적용한다. 근거가 없는 일정·장소·연락처·의무를 빨간색으로 만들어 채우지 않으며, 일반 텍스트 채널에서 지정 색상을 표현할 수 없으면 그 구체적 한계를 알린다. 게시·전송 여부는 별도 지시를 따른다.

근거 자료에서 학생이 알아야 할 사실만 골라, 복사해서 보낼 수 있는 공지글과 필요한 경우 공지 이미지를 만든다. 공지를 대신 게시하거나 전송하지 않는다.

## 근거 확인

1. PDF, HWP/HWPX, XLSX, 웹 공지 또는 사용자 제공 문구에서 관련 항목을 직접 확인한다. 표나 배치가 의미를 좌우하면 해당 페이지나 범위를 렌더링해 함께 검토한다.
2. 제목, 대상, 날짜, 시간, 장소, 신청·참여 방법, 마감, 메뉴 경로, 링크, 예외를 보호 사실로 기록한다. 서로 다른 항목의 날짜나 대상을 합치지 않는다.
3. 학생 대상 공지에서는 교직원용 보고, 내부 협조, 예산, 담당자 업무를 제외한다. 학생의 행동이나 참석 판단에 필요한 내용만 남긴다.
4. 근거가 없는 마감일, 연락처, 장소, 링크, 준비물, 혜택, 의무 표현을 만들지 않는다. 필요한 값이 없으면 해당 항목을 생략하고 사용자에게 `확인 필요`를 알린다.

## 공지글

카카오톡 화면에서 한 번에 읽히는 길이로 작성한다. 아래 요소 중 근거가 있는 것만 사용한다.

- 제목은 `📢`로 시작하고 행사명 또는 행동을 구체적으로 쓴다.
- 첫 문장은 대상과 안내 목적을 짧게 밝힌다.
- 날짜·시간, 장소, 신청·참여 방법, 주요 내용은 서로 다른 줄에 둔다.
- 학생이 해야 할 일이 있으면 기한과 함께 명령형이 아닌 정중한 요청으로 쓴다.
- 예외나 주의사항은 마지막 `※` 문장으로 분리한다.
- 실제 실행 링크나 정확한 시스템 메뉴 경로가 근거에 있으면 함께 제공한다.
- 날짜와 숫자의 값, 대응 관계, 목록 순서를 최종 문안과 근거 자료에서 다시 대조한다.

불필요한 인사말, 과장된 홍보 문구, 반복 설명, 내부 문서의 목차 표시는 넣지 않는다. 정보량이 많으면 전체 표를 옮기지 말고 학생의 일정과 행동 기준으로 요약한다.

## 공지 이미지

사용자가 지정한 달력형 등 구성과 형식을 우선한다. 별도 지정이 없으면 세로형 1080 x 1350 비율의 고대비 인포그래픽을 기본으로 한다.

- 제목, 핵심 날짜·시간, 장소 또는 행동을 가장 크게 배치한다.
- 여러 행사를 동등하게 안내하는 달력에서는 행사들을 같은 시각적 비중으로 표시한다. 날짜·시간 정정은 사실 수정이며 그 자체로 중요도를 뜻하지 않는다. 사용자 요청이나 근거 자료에 별도 우선순위가 없으면 정정된 행사에만 배지, 중복 강조문, 더 큰 카드나 다른 강조색을 쓰지 않는다.
- 별도 요청이 없는 일반 인포그래픽의 세부 일정은 3~7개 항목으로 간결하게 정리하고 긴 설명은 공지글로 보낸다. 사용자가 지정한 달력의 필수 일정은 임의로 생략하지 않는다.
- 학교명, 학과명, 로고, QR 코드, 연락처는 근거 또는 사용자 요청이 있을 때만 넣는다.
- 이미지 생성 프롬프트에 표시 문구를 인용하여 그대로 쓰고, 추가 문구를 금지한다.
- 인쇄용 공지 이미지는 최종 인쇄 크기에서 반드시 300dpi 이상으로 제작한다. 더 높은 해상도를 요청하면 그 기준을 따른다. A4 기준 약 2480 x 3508픽셀이며, 모바일용 기본 픽셀 수와 구분한다. 저장된 실제 픽셀 크기와 인쇄 크기로 양축 해상도를 검증하고 DPI 메타데이터만 바꾼 결과를 충분한 해상도로 판정하지 않는다. 확대본은 원본 세부 정보가 복구된 결과로 설명하지 않는다.
- 생성 후 한글, 날짜, 시간, 장소, 목록 누락과 글자 깨짐을 직접 확인한다. 달력형이면 선택한 구성이 유지되고 정정된 행사가 부당하게 강조되지 않았는지도 확인한다. 오류가 있으면 한 번에 한 가지 수정만 요청하여 다시 검증한다.

## 선택한 이미지의 부분 수정

여러 시안 중 하나를 골라 문구 교체를 요청하면 선택한 이미지와 요청한 문구·영역만 수정한다. 편집 전에 선택한 파일, 기존 문구, 정확한 교체 문구와 보호할 주변 문구를 확인하고 편집 지시에도 명시한다. 인접한 하단 문구를 포함한 나머지 텍스트와 배치는 보존한다. 대상·사실의 변경을 다른 시안이나 캘린더에 전파하지 않으며, 더 넓은 반영은 그 범위를 뒷받침하는 사용자 지시나 근거가 있을 때만 수행한다.

완료 전 선택한 원본과 최종 이미지를 비교하여 기존 교체 대상 문구가 남지 않았는지, 새 문구와 연결 조사가 정확한지, 주변 문구·배치가 보존되었는지 확인한다. 확인하지 못한 항목은 완료로 보고하지 않는다. 단순한 문구 변경 요청만으로 기존 근거를 오류였다고 단정하지 않는다.

## 전달

공지글과 이미지를 각각 구분해 제공한다. 이미지 파일은 사용자가 지정한 위치에 저장하고, 별도 지시가 없으면 현재 작업용 폴더에 비파괴적으로 저장한다. 근거에는 원본 파일명과 페이지·표·항목 등 가장 정확한 위치를 함께 적는다.
