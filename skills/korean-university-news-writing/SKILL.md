# 대학 홍보기사 작성

## 기사 목적과 근거를 확인한다

- 독자와 매체에 맞춰 초점을 정한다. 행사 기사에는 행사와 현장 활동을 앞세우고, 학과 소개 기사에는 교육과정이나 학생 지원을 본문 중심에 둔다. 사용자가 지정한 이전 원고와 게시 기사에서 제목, 부제, 첫 문단, 문단 길이, 인용과 사진 설명 방식을 확인한다. 참조 기사에서 이번 행사로 옮겨야 할 사실은 별도로 검증한다.
- 실제 운영을 다루는 기사라면 계획·공지·포스터, 사전 명단, 행사 후 확인, 사진·영상, 인터뷰를 근거별로 비교한다. 문서의 연도·회차·대상·행사명을 확인하고 이전 연도 자료는 사례로만 쓴다. 회의자료의 전체 프로그램 운영 기간과 해당 학과의 실제 행사 날짜를 구분한다.
- 참가 자격·모집 대상·참석 예정과 실제 참가 인원을 구분한다. 사용자가 실제 참석을 확인한 인원을 우선 반영하고 재학생, 외부 참가자, 진행진을 섞어 세지 않는다. 외부 참가자의 등록·합격·지원 여부나 소속별 인원이 확인되지 않으면 기사에는 전공체험 참가자처럼 확인 가능한 표현을 쓴다. 사진 속 인원만 세어 참석자 수나 개인의 역할을 확정하지 않는다. 이미 작성한 기사에서 사용자가 특정 참가 집단의 인원만 정정하면 최신 저장본에서 그 집단의 수치와 그 수치에 의존하는 기사 내 합계·반복 표기만 갱신한다. 저장 후 정정한 수치가 해당 집단에 연결되고 다른 집단의 인원과 나머지 문구가 보존됐는지 대조한다.
- 행사 자료에는 주최와 지원부서, 협력기관, 담당자 직함, 프로그램 주제, 사업명을 구분해 확인한다. 기존 기사가 실린 사이트나 뉴스레터의 이름만으로 해당 행사의 사업 재원이나 공동 주최를 판단하지 않는다. 확인되지 않은 정보가 핵심이면 사용자에게 좁혀 묻고, 나머지는 근거가 확보된 내용으로 초안을 완성한다.

## 기사에 실을 현장 사진을 보정한다

- 기사에 실을 사진은 원본에서 구도, 수평, 노출, 색을 먼저 보정한다. 이미지 생성으로 전체 장면을 편집하면 얼굴·손동작·인원이나 화면 속 발표 자료가 달라질 수 있다. 기사 편집본을 원본과 나란히 확인하고 사람, 현장 물건과 발표 자료가 달라진 시안은 제외한다.
- 현수막의 주최·주관처럼 사용자가 보완을 요청한 문구는 확인된 원본 자료를 사용해 해당 표시 영역만 수정한다. 실제 빔 화면이라면 기존 화면의 원근, 밝기, 색온도와 선명도에 맞춰야 한다. 저장한 전체 사진과 현수막 확대본에서 합성 경계와 글자를 확인한다. 촬영 당시와 달라진 문구를 밝혀야 할 때는 사진 설명이나 전달문에 해당 변경을 구체적으로 알린다.
- 전달할 기사 사진의 파일명은 행사나 장면이 드러나도록 짓는다. 사용자가 직접 요구하지 않은 제작 방식이나 보정 단계는 파일명에서 뺀다. 예를 들어 `01_단체사진.png`, `02_강의현장.jpg`처럼 이름을 붙인다. 저장 후 최종 폴더에서 파일명을 읽어 불필요한 작업 표기가 남았는지 확인하고, 보관한 촬영 원본의 이름은 유지한다.

## 제목·본문·사진 설명을 작성한다

- 제목에 대학 또는 학과와 구체적인 활동을 넣는다. 부제를 쓰는 매체라면 핵심 프로그램, 대상, 재학생의 참여 방식 등 제목에 없는 사실을 한 줄로 보탠다. 첫 문단에는 확인된 주체·일자·장소·핵심 활동 가운데 독자에게 필요한 정보를 담고, 본문은 취지와 구체적인 장면을 이어 쓴다.
- 내부 모집 목표는 독자에게 제공된 활동과 교육 기회를 중심으로 풀어 쓴다. 근거 없는 성과·만족도와 관행적인 과장 표현을 덧붙이지 않는다. 게시용 확정 인용은 실제 발언 또는 당사자가 확정한 인용문을 사용하고, 원문과 인용자의 이름·직함을 대조한다. 사용자가 기사에서 직접 손볼 인터뷰 문안을 요청했거나 이를 기본값으로 지정했다면, 최신 지시로 정한 인터뷰 대상에 한해 기사 본문에 편집 가능한 인용문을 넣는다. 사용자가 표시 문구 생략을 지시하면 인용문에 별도 표지를 붙이지 않는다. 미확정 문구에 적용되는 색상 지시가 있으면 해당 발언 본문만 정확히 표시하고, 전달 시 문안이 수정용임을 기사 밖에서 알린다.
- 사진 설명은 파일을 직접 확인해 이미지에 담긴 활동·장면에 맞춘다. 행사 전체를 설명하는 사진과 핵심 활동이 보이는 사진을 고를 수 있다. 보관 요청은 기존 행사 업무철과 대상 파일을 확인한 뒤 수행한다. 원본 파일명과 파일 내용을 보존하고, 보관 경로에서 수량과 해시를 대조한다. 사진 선별, 원본 보관, 대외 게시를 각각 요청 범위에 맞춰 수행한다.
- 한국어 문장은 사용 가능한 한국어 작성, 문체 일관성, 맞춤법 검수 절차를 활용한다. 보도 문체는 자연스러운 서술형 문장으로 유지하며 출처·편집 메모는 기사 본문 밖에 둔다.

## 전달 전 확인한다

- 저장본 또는 전달문을 다시 읽어 날짜·장소·행사명·활동 순서·인원·대상 호칭·인용·사진 설명을 근거와 대조한다. 특히 사용자가 행사 순서나 활동의 동시 진행을 정정했다면 해당 관계가 본문에 드러나는지 확인한다. 인터뷰 대상이 제한되면 저장본에서 인용 단락 수와 화자를 대조하고 제외된 대상의 인용이 남지 않았는지 확인한다. 기사마다 모든 항목을 반드시 기재할 필요는 없다. 출처가 충돌하면 어떤 근거를 택했는지 사용자에게 알린다.
- 기사 제목·본문·요청된 사진 설명을 복사하거나 편집할 수 있는 상태로 제공한다. 기사 작성 요청은 실제 게시나 배포와 구별하고, 게시·전송은 사용자가 요청한 경우에만 진행한다.
