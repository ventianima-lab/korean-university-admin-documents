# Format routing

- HWPX or legacy HWP: use `hancom-hwpx-documents`; use `hwp-to-hwpx-converter` when conversion is actually required.
- DOCX or Word template: use `docx-template-editor`.
- XLSX or spreadsheet form: use `spreadsheet-form-preservation`.
- Photographed pages: use `document-scan-cleaner` before document assembly.
- PDF: inspect text and render every relevant page; preserve signatures, seals and page order. Do not claim editability when the PDF is only a scan.
- Korean prose: use `korean-admin-writing` after facts and protected fields are fixed.

Use the supplied format unless the user asks for conversion. A successful conversion is not permission to discard the source.
